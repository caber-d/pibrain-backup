Privacy policy

pibrain backup is a personal tool used only by its owner.

  • It asks Google for the drive.file permission only, so it can see and change only the files it creates itself in the owner's own Google Drive. It cannot see any other files.
  • Everything it stores is encrypted on the owner's server before upload; Google holds only encrypted data.
  • It collects no data about anyone, uses no analytics or cookies, and shares nothing with third parties.
  • Access can be withdrawn at any time from the Google Account's security settings ("Third-party apps with account access").
